# Sandbox

Sandbox is an Unreal Engine 5.8 prototype for experimenting with character animation, interaction, dialogue, and the Gameplay Ability System.

The goal of this project is to create a demo for having a conversation over a shared meal, with a focus on creating an immersive and interactive gameplay experience.

The project includes a runtime game module, custom gameplay systems, and an editor/runtime plugin for authoring dialogue.

## Project Overview

This project is built with:

- Unreal Engine 5.8
- C++20
- Gameplay Ability System
- Enhanced Input

## Features

### Meal System

- Actor components for food serving and meal participation
- Gameplay Abilities for meal interactions (eating food, calling waiter)
- Three food types (drinks, handhelds, and mains) with different behavior and animations

### Interaction System

- The player can directly move either hand to interact with food on the table, or to point to items on the menu to order them
